# 聊天室与 GitHub 连续任务实现计划

**目标：** 将聊天室任务与授权仓库中的 PR、评论及决定关联，保证重启后仍能追踪同一任务。

**架构：** 持久化连续任务、来源事件和当前决定；GitHub 适配器只访问配置的仓库，并记录游标与去重键。执行器使用独立工作区及现有任务调度，失败时保留可检查状态。已有主动协助改动继续保留。

**技术：** FastAPI、SQLite、httpx、Git、Vue；所有自动测试使用模拟提供方及临时仓库。

**设计：** `docs/superpowers/specs/2026-11-01-cross-platform-continuity.md`

1. 新增持久化关联及事件状态，测试重复事件、隔离、历史和重启恢复。
2. 增加 GitHub 适配器，测试只允许配置仓库、分页与限流错误，不泄露密钥。
3. 将已关联 PR 的评论映射到任务，并把最新明确方向加入任务上下文；测试无关及未经授权事件被拒绝。
4. 加入隔离工作区、受控分支和草稿 PR 操作，验证基线与并发变更；更新聊天室进度展示。
5. 完整测试已有聊天、多人任务和新流程，区分模拟验证与真实 GitHub 联调。
